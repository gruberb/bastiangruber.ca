# Changelog

All notable changes to this site are documented here.

The format is loosely based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- Dark mode that follows the system setting, with a toggle in the top bar that remembers the choice.
- Blog index search (`/` to focus) and topic filters; posts grouped by year.
- Article table of contents rendered at build time, with scroll tracking in the sidebar and a collapsible version on narrow screens.
- Numbered article sections and heading anchor links.
- Labelled code block header with language and copy button, including fences without a language.

### Changed
- Redesign of home, blog index, articles and topic pages: monospace labels, hairline dividers, lighter headings, post rows instead of cards.
- Sticky top bar with breadcrumb and reading progress; new footer.
- Syntax highlighting colors now come from theme tokens instead of the Prism One Light theme.
- Talks, Projects and About headers restyled to match.
- Point Fantasy Puck links to the new `fantasy-puck.ca` domain (projects page and `love-my-tools` blog post).
